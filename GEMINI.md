# Gojiberry

Gojiberry is a B2B prospecting workspace. The Gojiberry MCP tools talk to the user's account. Call only tools the server actually exposes. Do not invent a tool name, field, or filter.

A list holds contacts. Adding a contact to a list enrolls them in the campaign linked to that list. A lead-finding agent imports leads into its list. A campaign runs outreach on the contacts of its lists.

Use read-only tools freely: list and get contacts, lists, campaigns, and lead-finding agents, intent counts, and Unibox threads and messages.

Show the exact change and wait for an explicit yes before creating or updating contacts, lists, or campaigns, before adding or removing contacts from a list, before enriching an email (1 credit when it succeeds), and before sending a LinkedIn reply.

The API key comes from app.gojiberry.ai → Settings → API. It is sent as Authorization: Bearer to https://mcp.gojiberry.ai/mcp.
